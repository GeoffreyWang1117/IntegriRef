# IntegriRef Paper

Research manuscript: "IntegriRef: A Five-Layer Bayesian Framework for Cross-Domain Reference Integrity Verification"

## Build

```bash
cd paper/
make          # requires pdflatex
make clean    # remove build artifacts
```

## Structure

- `main.tex` — Full manuscript (ACM sigconf format)
- `Makefile` — Build automation
- `figures/` — Figures (to be generated from benchmark data)

## Experimental Data

Benchmark results are generated by:
```bash
python -m benchmarks.ablation --verbose --output paper/ablation_results.json
python -m benchmarks.bench_pipeline_throughput --output paper/throughput_results.json
```
