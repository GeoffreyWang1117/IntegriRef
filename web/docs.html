Quick Start

Get IntegriRef running in under 5 minutes.

Requirements: Python 3.10+, pip. GPU optional (CPU heuristic fallback available for all layers).

Installation

Basic Install

# Clone the repository
git clone https://github.com/integriref/integriref.git
cd integriref

# Install dependencies
pip install -r requirements.txt

# Verify installation
python -c "from core.discovery import RegistryDiscovery; print('OK')"

With Acceleration (recommended)

# Install async + caching support
pip install aiohttp uvloop redis[hiredis]

# Install ONNX Runtime for fast CPU inference
pip install onnxruntime

# For GPU inference
pip install torch transformers

Model Downloads

# L1: Citation Intent (SciBERT fine-tuned on SciCite)
# Auto-downloads on first use, or set manually:
export INTENT_MODEL_PATH=models/intent_classifier

# L2: Semantic Verification (DeBERTa-v3 fine-tuned on SciFact)
export NLI_MODEL_PATH=models/scifact_nli

# ONNX model (optional, for CPU acceleration)
# Export from PyTorch:
python -c "
from semantic.onnx_exporter import export_to_onnx
export_to_onnx('models/scifact_nli', 'models/scifact_nli/model.onnx', quantize=True)
"

Async API (recommended for batch)

import asyncio
from core.async_discovery import AsyncRegistryDiscovery
from core.batch_processor import BatchProcessor

async def main():
    discovery = AsyncRegistryDiscovery()
    discovery.register_all(all_adapters)

    # Single async verification
    result = await discovery.verify_reference(
        title="Deep Residual Learning",
        identifier="10.1109/CVPR.2016.90"
    )
    print(result)

    # Batch verification (32 concurrent)
    processor = BatchProcessor(discovery, max_concurrent=32)
    references = [
        {"title": "Paper 1", "doi": "10.xxx/1"},
        {"title": "Paper 2", "doi": "10.xxx/2"},
        # ... hundreds of references
    ]
    results = await processor.verify_batch(references)

asyncio.run(main())

Architecture Overview

IntegriRef uses a five-layer verification stack, where each layer adds progressively deeper analysis. Layers are independent and can be used individually or combined.

  Request (DOI/title/metadata)
       │
       ▼
  ┌─────────────┐     ┌──────────────────┐
  │  L0: Exist  │────▶│  62 Registries   │  Existence + field matching
  └──────┬──────┘     └──────────────────┘
         │
         ▼
  ┌─────────────┐     ┌──────────────────┐
  │  L1: Intent │────▶│  SciBERT / cues  │  Supporting / Mentioning / Contrasting
  └──────┬──────┘     └──────────────────┘
         │
         ▼
  ┌─────────────┐     ┌──────────────────┐
  │ L2: Semantic│────▶│  DeBERTa NLI     │  Claim ↔ abstract alignment
  └──────┬──────┘     └──────────────────┘
         │
         ▼
  ┌─────────────┐     ┌──────────────────┐
  │  L3: Graph  │────▶│  OpenAlex 2-hop  │  7 anomaly detectors

         │
         ▼

ICEntity Model

The ICEntity (Integrity-Checked Entity) is the universal data model for all verified entities. Every registry adapter returns normalized ICEntity objects.

from core.entity import ICEntity, EntityType

entity = ICEntity(
    entity_type=EntityType.JOURNAL_ARTICLE,
    title="Attention Is All You Need",
    authors=["Vaswani, A.", "Shazeer, N."],
    year="2017",
    venue="NeurIPS",
)
entity.add_external_id("crossref", "doi", "10.48550/arXiv.1706.03762")
entity.normalize()  # Standardize title, authors, year

Entity types: journal_article, conference_paper, preprint, book, book_chapter, thesis, patent, legal_case, government_report, standard, dataset, unknown

Each registry adapter implements three methods: info(), query_by_id(), and search(). Built-in features include rate limiting, circuit breakers, and exponential backoff retry.

Writing a Custom Adapter

from core.registry import RegistryAdapter, RegistryInfo
from core.entity import ICEntity, EntityType

class MyRegistryAdapter(RegistryAdapter):
    def info(self):
        return RegistryInfo(
            name="my_registry",
            domain="academic",
            base_url="https://api.example.com",
            auth_type="api_key_free",
            rate_limit=0.1,  # seconds between requests
            coverage="Example papers database",
            entity_types=["journal_article"],
        )

    def query_by_id(self, id_type, id_value):
        resp = self._get(  # Built-in retry + circuit breaker
            f"{self.info().base_url}/works/{id_value}")
        if not resp:
            return None
        data = resp.json()
        entity = ICEntity(
            entity_type=EntityType.JOURNAL_ARTICLE,
            title=data["title"],
            authors=data.get("authors", []),
            year=str(data.get("year", "")),
        )
        entity.normalize()
        return entity

    def search(self, title, author="", year="", **kw):
        resp = self._get(f"{self.info().base_url}/search",
                         params={"q": title})
        if not resp:
            return []
        return [self._parse(item) for item in resp.json()["results"]]

Registry Discovery

RegistryDiscovery is the routing layer that automatically determines which registries to query based on identifier type and domain.

from core.discovery import RegistryDiscovery

discovery = RegistryDiscovery()
discovery.auto_register()  # Register all 62 adapters

# Auto-detects ID type and routes to matching registries
results = discovery.parallel_query_by_id("doi", "10.1038/s41586-020-2649-2")
# → queries Crossref, OpenAlex, Semantic Scholar, etc. in parallel

# Search fallback
results = discovery.parallel_search("Attention Is All You Need")

# ID type detection
RegistryDiscovery.detect_id_type("10.1038/s41586-020-2649-2")  # → "doi"
RegistryDiscovery.detect_id_type("US10,123,456")               # → "patent_number"
RegistryDiscovery.detect_id_type("978-0-13-468599-1")           # → "isbn"

L0: Existence Verification

The foundation layer verifies that a cited reference actually exists in authoritative registries and matches the claimed metadata.

Core Components

  • VerificationEngine (verification/engine.py): Orchestrates the full verification pipeline
  • FieldComparator (verification/field_comparator.py): Title, author, year, venue fuzzy matching (RapidFuzz + Jaccard)
  • HallucinationDetector (verification/hallucination_detector.py): Multi-signal fake reference detection at 336K refs/s
  • RetractionChecker (verification/retraction_checker.py): Crossref retraction status
from verification.engine import VerificationEngine

engine = VerificationEngine(discovery)

# Full L0 verification
result = engine.verify({
    "title": "Deep Residual Learning for Image Recognition",
    "doi": "10.1109/CVPR.2016.90",
    "year": "2016",
    "authors": ["He", "Zhang", "Ren", "Sun"]
})

# result.found → True
# result.composite_score → 0.95
# result.field_scores → {"title": 0.98, "author": 0.92, "year": 1.0}
# result.registries_hit → ["crossref", "openalex", "semantic_scholar"]

L1: Citation Intent Classification

Classifies how a paper cites another: Supporting (confirms findings), Mentioning (background reference), or Contrasting (challenges/disagrees).

from semantic.intent_classifier import IntentClassifier

classifier = IntentClassifier()

result = classifier.classify(
    "Following the approach of He et al. (2016), we use residual connections"
)
# result.label → "supporting"
# result.confidence → 0.89

result = classifier.classify(
    "Unlike the findings of Smith (2020), our results show..."
)
# result.label → "contrasting"
# result.confidence → 0.82
CPU fallback: Without GPU/model, IntentClassifier uses a heuristic lexical-cue system (3,471 refs/s) that still provides reasonable classification.

L2: Semantic Claim Verification

Verifies whether the citing paper's claim is actually supported, contradicted, or unrelated to the cited abstract. Uses DeBERTa-v3 fine-tuned on SciFact (93.5% accuracy).

from semantic.nli_verifier import NLIVerifier

verifier = NLIVerifier()

result = verifier.verify(
    claim="Transformer models outperform RNNs on machine translation",
    abstract="We propose a new architecture based solely on attention mechanisms. "
             "Experiments on WMT 2014 show the model achieves 28.4 BLEU, "
             "surpassing the best previously reported results including RNN-based models."
)
# result.label → AlignmentLabel.SUPPORTED
# result.confidence → 0.91
# result.entailment_score → 0.93
# result.contradiction_score → 0.02

ONNX Accelerated (2.2x faster on CPU)

from semantic.onnx_exporter import ONNXNLIVerifier

# Drop-in replacement — same interface
verifier = ONNXNLIVerifier(
    onnx_path="models/scifact_nli/model_int8.onnx",
    tokenizer_path="models/scifact_nli",
    num_threads=4
)
result = verifier.verify(claim, abstract)  # Same API

# Batch verification
pairs = [(claim1, abstract1), (claim2, abstract2), ...]
results = verifier.verify_batch(pairs, batch_size=64)

L3: Citation Graph Analysis

Builds 2-hop citation graphs from OpenAlex and runs 7 anomaly detection algorithms.

from graph.openalex_builder import OpenAlexGraphBuilder
from graph.anomaly import AnomalyDetector
from graph.metrics import GraphMetrics

# Build 2-hop citation graph
builder = OpenAlexGraphBuilder()
graph = builder.build_two_hop(doi="10.1038/s41586-020-2649-2")

# Run anomaly detection
detector = AnomalyDetector(graph)
anomalies = detector.detect_all()

for a in anomalies:
    print(f"{a.type}: {a.description} (severity: {a.severity})")

# Graph health score
metrics = GraphMetrics(graph)
health = metrics.compute_health_score()
# health.overall → 0.85 (0-1 scale)
# health.dimensions → {interconnection: 0.9, temporal: 0.95, ...}

L4: Bayesian Risk Scoring

Combines all signals from L0-L3 using a Bayesian framework with literature-derived likelihood ratios to produce a calibrated risk probability.

from scoring.bayesian import BayesianRiskScorer

scorer = BayesianRiskScorer(domain="cancer_research")  # prior=10%

risk = scorer.score({
    "reference_not_found": (True, 0.9),     # (present, confidence)
    "tortured_phrases": (True, 0.95),       # LR+ = 25.0
    "grim_test_failure": (False, 0.8),      # LR- = 0.99
    "citation_ring_detected": (False, 0.7), # LR- = 0.90
})

# risk.probability → 0.81
# risk.tier → "CRITICAL"
# risk.signals_fired → ["reference_not_found", "tortured_phrases"]
# risk.explanation → "Prior 10% → Posterior 81% (2 positive signals)"

Detection Modules

Hallucination Detection

Multi-signal detection of fabricated references (LLM-generated, paper-mill, etc.) at 336K refs/s.

from verification.hallucination_detector import HallucinationDetector

detector = HallucinationDetector()
result = detector.analyze({
    "title": "A Novel Approach to Quantum Computing",
    "doi": "10.9999/fake-journal.2024.001",
    "year": "2030",
    "authors": ["Smith, J."]
})
# result.is_suspicious → True
# result.signals → ["invalid_doi_prefix", "future_year", ...]

Tortured Phrase Detection

281 paper-mill signature phrases detected via Aho-Corasick automaton (single-pass).

from verification.tortured_phrases import TorturedPhraseDetector

detector = TorturedPhraseDetector()
result = detector.scan("This study uses profound learning and arbitrary forest...")
# result.matches → [("profound learning", "deep learning"), ("arbitrary forest", "random forest")]
# result.score → 55

Statistical Verification

GRIM test (mean mathematical consistency) + statcheck (p-value recomputation).

from verification.statistical import StatisticalVerifier

verifier = StatisticalVerifier()
result = verifier.check_text("M = 2.31, SD = 0.5, N = 25; t(24) = 3.45, p = .002")
# result.grim_results → [GRIMResult(mean=2.31, n=25, consistent=True)]
# result.statcheck_results → [StatResult(stat="t", df=24, value=3.45, reported_p=0.002, computed_p=0.002, consistent=True)]

Sneaked Reference Detection

Compares Crossref metadata references vs in-text citations to find inserted references.

from verification.sneaked_references import SneakedReferenceDetector

detector = SneakedReferenceDetector()

# result.sneaked_ratio → 0.15
# result.sneaked_refs → [...]
# result.journal_concentration → 0.45 (HHI)

Performance & Acceleration

IntegriRef includes a production-grade acceleration stack for high-throughput deployments.

ONNX Inference

Export DeBERTa-v3 to ONNX with INT8 quantization for 2.2x CPU speedup (79% of GPU performance).

    model_path="models/scifact_nli",
    output_path="models/scifact_nli/model.onnx",
    optimize=True,
    quantize=True,  # INT8 → 233MB (vs 704MB FP32)

# Use for inference
verifier = ONNXNLIVerifier(
    onnx_path="models/scifact_nli/model_int8.onnx",
    num_threads=4,
